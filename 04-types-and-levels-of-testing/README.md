# Проект 4. Виды, уровни и методы тестирования

Систематизация видов и уровней тестирования ПО, методы анализа приложений и тестирование документации.

## 📚 Теория и темы модуля:
* Виды тестирования.
* Уровни тестирования.
* Тестирование требований и спецификаций.
* Методы тестирования (Black-box, White-box, Grey-box).
* Итоговая классификация и составление стратегии тестирования.
