# Проект 3. Техники тест-дизайна и покрытие

Практический модуль по оптимизации количества проверок и обеспечению максимального тестового покрытия с помощью техник тест-дизайна.

## 📚 Теория и темы модуля:
* Классы эквивалентности (Equivalence Partitioning).
* Граничные значения (Boundary Value Analysis).
* Таблицы решений и Диаграммы состояний и переходов (State & Transition).
* Попарное тестирование (Pairwise Testing).
* Исследовательское тестирование, тестовые туры и Error Guessing.
* Матрица покрытия требований (Traceability Matrix).
