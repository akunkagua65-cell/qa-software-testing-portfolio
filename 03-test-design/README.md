# Проект 3. Техники тест-дизайна и покрытие

Практический модуль по применению техник тест-дизайна для оптимизации количества проверок и обеспечения максимального тестового покрытия.

## 📚 Теория и темы модуля:
* Классы эквивалентности.
* Граничные значения.
* Таблица переходов и состояний.
* Попарное тестирование (Pairwise).
* Исследовательское тестирование и тестовые туры.
* Матрица покрытия требований (Traceability Matrix).
