# 🧪 QA & Software Testing Portfolio

Привет! Меня зовут Алёна. В этом репозитории собраны практические проекты и тестовые артефакты, выполненные в ходе обучения в Школе 21 (Сбер) по направлению Тестирование ПО (QA / QC).

Программа охватывает полный цикл тестирования ПО: от работы с требованиями и документацией до API, Web, мобильного тестирования и SQL.

---

## 🛠 Технологический стек и инструменты

* Теория и методология: SDLC, STLC, ISTQB, QA vs QC, Виды и уровни тестирования, Принципы тестирования.
* Тест-дизайн: Классы эквивалентности, Анализ граничных значений, State & Transition Diagram, Pairwise (Попарное тестирование), Error Guessing, Тестовые туры, Матрица покрытия.
* Тестовые артефакты: Тест-планы, Тест-кейсы, Чек-листы, Баг-репорты (жизненный цикл и локализация), Чит-листы, Тестовые сценарии.
* Web & API: REST API, Postman, Swagger, Chrome DevTools, HTTP/HTTPS, Client-Server architecture, Cookies, HTML Validation, UI Testing.
* Базы данных & Инструменты: SQL (Базы данных), Git, GitHub, VS Code.

## 📂 Структура портфолио (Модули)

### [01. Введение в тестирование](./01-introduction-to-testing)
* Изучение стандарта ISTQB и разбор ключевых принципов тестирования.
* Отличия QA от QC и роли в жизненном цикле разработки ПО (SDLC).

### [02. Основные и вспомогательные тестовые артефакты](./02-test-artifacts)
* Разработка Тест-кейсов, Чек-листов и Тест-плана.
* Работа с тестовыми данными, чит-листами и составление тестовых сценариев.

### [03. Техники тест-дизайна и покрытие](./03-test-design)
* Практика применения Классов эквивалентности и Граничных значений.
* Построение Таблиц переходов и состояний и оптимизация проверок методом Pairwise.
* Проведение исследовательских Тестовых туров и построение Матрицы тестового покрытия.

### [04. Виды и уровни тестирования](./04-types-and-levels-of-testing)
* Классификация видов и уровней тестирования ПО.
* Практическое тестирование требований и спецификаций.
* Применение подходов Black-box и Grey-box.

### [05. Дефекты и баг-репорты](./05-defects-and-bug-reports)
* Классификация видов и причин возникновения дефектов.
* Локализация багов, оформление Баг-репортов и отслеживание их жизненного цикла.

### [06. Веб-тестирование и DevTools](./06-web-and-devtools)
* Тестирование клиент-серверной архитектуры с помощью Chrome DevTools.
* Анализ протоколов HTTP/HTTPS, работы Cookies и движков браузеров.
* Валидация HTML и тестирование UI веб-сайта.

### [07. Backend, API и Базы данных](./07-backend-api-and-db)
* Тестирование архитектуры REST API с использованием Postman и документации Swagger.
* Работа с Базами данных и составление SQL-запросов.
