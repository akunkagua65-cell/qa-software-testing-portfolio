# Проект 1. Основы тестирования ПО и SDLC

В данном модуле изучены базовые понятия теории тестирования, процессы обеспечения качества, модели жизненного цикла разработки ПО (SDLC), а также международные стандарты ISTQB.

## 📚 Теория и темы модуля:
* Понятия QA (Quality Assurance) и QC (Quality Control), их ключевые различия.
* Жизненный цикл разработки ПО (SDLC) и место тестирования в нем (STLC).
* Стандарты и терминология ISTQB.
* 7 базовых принципов тестирования.
* Анализ требований и выявление дефектов на ранних стадиях.
