# Проект 2. Основные и вспомогательные тестовые артефакты

Модуль посвящен разработке и ведению ключевой тестовой документации. Все артефакты составлены с учетом требований к структуре, понятности и тестовому покрытию.

## 📚 Теория и темы модуля:
* Структура и назначение Тест-плана (Test Plan).
* Правила составления Тест-кейсов (Test Cases) и Чек-листов (Checklists).
* Оформление отчетов об ошибках (Bug Reports), определение Severity и Priority.
* Сценарии использования (Use Cases) и Пользовательские истории (User Stories).
* Вспомогательные чит-листы и тестовые сценарии.
