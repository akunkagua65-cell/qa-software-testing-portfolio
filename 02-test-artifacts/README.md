# Модуль 2. Основные и вспомогательные тестовые артефакты

В рамках проекта разработана тестовая документация для проверки функционала ПО. Все артефакты составлены с соблюдением требований к структуре и полноте покрытия.

## Состав проекта:
1. **Тест-кейсы (test-cases.md):** Разработка тестовых наборов с предусловиями, шагами и ожидаемыми результатами.
2. **Чек-листы (check-lists.md):** Составление и дополнение чек-листов для быстрых проверок функционала.
3. **Баг-репорты (bug-reports.md):** Оформление отчетов об ошибках с указанием Severity/Priority, окружения и шагов воспроизведения.
4. **Тест-план (test-plan.md):** Разработка стратегии тестирования, целей, критериев начала и завершение. Чит-листы и тестовые сценарии:** Составление сценариев использования (Use Cases), подготовка тестовых данных и вспомогательных чит-листов.
