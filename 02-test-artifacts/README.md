# Проект 2. Основные и вспомогательные тестовые артефакты

Модуль посвящен разработке и ведению ключевой и вспомогательной тестовой документации.

## 📚 Теория и темы модуля:
* Основные тестовые артефакты (Тест-кейс, Чек-лист, Тестовый набор, Баг-репорт, Тест-план).
* Вспомогательные тестовые артефакты (Чит-лист, Тестовые данные, Тестовый сценарий, Сценарий использования).
