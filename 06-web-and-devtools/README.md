# Проект 6. Веб-тестирование и DevTools

Модуль посвящен веб-тестированию: от клиент-серверной архитектуры до использования Chrome DevTools, анализа HTTP/HTTPS, работы с Cookies и валидации HTML.

## 📚 Теория и темы модуля:
* Средства разработчика Chrome DevTools.
* Движки браузеров.
* Протоколы HTTP и HTTPS.
* Cookies.
* UI/UX-тестирование.
* Валидаторы HTML.
