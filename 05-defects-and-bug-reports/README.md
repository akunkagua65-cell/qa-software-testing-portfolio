# Проект 5. Дефекты и баг-репорты

Модуль посвящен классификации дефектов, причинам их появления, составлению баг-репортов и жизненному циклу дефекта.

## 📚 Теория и темы модуля:
* Баг (дефект).
* Виды дефектов.
* Причины появления дефектов.
* Локализация дефекта.
* Баг-репорт.
* Жизненный цикл баг-репорта.
